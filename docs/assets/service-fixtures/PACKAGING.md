# Published source layout

The original S01 source and geometry are retained. The verifier paths were adjusted to the adjacent mechanical, body-power, wheels and corners folders in this public asset package. No geometry was changed. The original S01 checks use C02_R05; the current C02_R06 entry-relief correction is strictly subtractive with identical poses and preserves these fixture clearances. Fixtures are static workholding studies, not rated lifting equipment or approved hardware.
